fig5 share package

This package contains:
- `draw_fig5_bcp_cer.py`: the copied plotting script
- `data/`: all JSON source files needed by the script

Run:

```bash
python draw_fig5_bcp_cer.py
```

Outputs will be written into this same directory:
- `fig5_bcp_cer_scatter.png`
- `fig5_bcp_cer_scatter.pdf`
- `fig5_bcp_cer_sources.json`
