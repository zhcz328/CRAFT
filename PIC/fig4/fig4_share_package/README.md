fig4 share package

This package contains:
- `draw_fig4_layer_trace.py`: the copied plotting script
- `data/`: all JSON source files needed by the script

Run:

```bash
python draw_fig4_layer_trace.py
```

Outputs will be written into this same directory:
- `fig4_layer_trace.png`
- `fig4_layer_trace.pdf`
- `fig4_layer_trace_sources.json`
